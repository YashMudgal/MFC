## 🛠️ Core Services Offered
Our comprehensive facilities maintenance services are structured into two specialized groups:

### 1. Cleaning & Sanitization Services
*   **Duct Cleaning & HVAC Sanitization**: Commercial & industrial HVAC duct sanitization, particulate removal, and indoor air quality compliance testing.
*   **Janitorial & Office Cleaning**: Tailored daily, weekly, or post-construction maintenance for offices, retail, and strata common areas.
*   **Window Cleaning**: Crystal clear interior & exterior glass washing using purified water-fed poles and high-reach certified teams.
*   **Carpet Steam Cleaning & Restoration**: Deep hot-water steam extraction, commercial stain treatments, and fast-drying carpet fiber restoration.
*   **Pressure Washing & Exterior Detailing**: High-pressure washing for parkades, concrete walkways, building siding, grease removal, and moss treatment.

### 2. Paving & Parking Lot Services
*   **Asphalt Paving & Repairs**: Parking lot construction, pothole repairs, hot asphalt patching, sealcoating, and structural sub-base grading.
*   **Line Painting & Parking Lot Layout**: High-visibility parking stall line striping, stenciling, fire lane markings, and custom safety layout design.

## 💻 Local Development Setup
To run and preview the website locally:

1.  **Clone the Repository**:
    ```bash
    git clone https://github.com/YashMudgal/MFC.git
    cd MFC
    ```
2.  **Start Local Development Server**:
    Using `npm` to serve static pages locally:
    ```bash
    npm run dev
    ```
3.  **View Website**:
    Open [http://localhost:8080](http://localhost:8080) in your web browser.
